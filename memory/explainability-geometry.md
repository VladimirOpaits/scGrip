2026-07-07: Started the explainability phase Guillem asked for ("why does it improve? what diversity is selected?"). Frame = shortcut learning / cows-on-beach (Beery 2018, Geirhos 2020): study/assay = background, tumor/normal = object; homogeneous cohort keys on background, inverts on new batch (explains AUC<0.5). Goal = **show biology influences geometry**, uniting the geometric and biological readings.

**Setup** ([[crc-atlas-base]]): patient signature lives in 1024-dim RFF space; LR learns weight vector `w`. Define two axes IN that space, each controlling the nuisance:
- `d_bio` = mean(tumor)−mean(normal) WITHIN each study (batch fixed), averaged.
- `d_batch` = mean(assay A)−mean(assay B) WITHIN each sample_type (biology fixed), averaged.
Orthonormalize → 2D canvas; project `w` → watch it rotate. Angle(d_bio,d_batch)≈81–97° (near-orthogonal → premise holds; not a tautology). In-plane ‖proj‖/‖w‖≈0.5–0.7 (honest: ~half of w captured by the plane).

**Key experiment** (`scripts/explain_confound.py`): purest confound — seed = 12 tumors from tech A (10x 3' v3) + 12 normals from tech B (10x 5' v1), so label⟺batch perfectly in training. Then ADD/REPLACE diverse same-label samples from OTHER techs; one fixed-frame LR gives BOTH geometry and held-out AUC.

**Results (corrected):**
- ROTATION confirmed: k=0 cos(w,batch)=0.65, cos(w,bio)=0.34 → diversity pushes cos_batch↓, cos_bio↑.
- GEOMETRY ↔ PERFORMANCE: as w rotates, held AUC recovers 0.65 → 0.88–0.91. Same motion, two readouts. This is the "why it works" chain for Guillem.
- REPLACE vs ADD — RETRACTED the "REPLACE>ADD" claim. At the pathological ρ=1.0 (perfect confound) replace rotates fully (cos_batch→−0.06, cos_bio→0.61, AUC 0.91 vs add 0.88), which LOOKED like REPLACE>ADD. But a confound-severity sweep (`scripts/explain_confound_sweep.py`, ρ = frac(tumor from A)=frac(normal from B), ρ=0.5→1.0) shows the OPPOSITE in realistic regimes: baseline drops monotonically 0.87→0.66 with ρ (valid knob); ADD recovers to ~0.9 flat across ALL ρ (0.93→0.88); REPLACE−ADD gap is NEGATIVE (ADD wins by 0.03–0.05) for ρ=0.5–0.8, ties at 0.9, positive only at ρ=1.0 (+0.02). Crossover ρ≈0.93. **Correct claim: ADD ≥ REPLACE in realistic partial confound — keep all data, grow the cohort; replacement only pays at absolute confound.** Vindicates the ADD-as-realistic-use-case [[next-experiment-greedy-enrichment]]. Lesson: user caught me generalizing from an extreme corner; sweep the nuisance level before claiming an ordering.
- quantile faster than random early (k=2: 0.86 vs 0.81), converge by k=12 — front-loading/speed edge again, consistent with selector≈random-on-endpoint.

**Why selector≈random RESOLVED (q-contrast, `scripts/explain_qcontrast.py`, ρ=1.0 ADD):** user's diagnosis confirmed & quantified — our pool is so diverse that a RANDOM draw is already a FAR draw. Mean distance-to-seed of picks: q=0.1→25, q=0.5→30, q=0.9→38, **random→36** (random sits in the far regime, so there's no gap to beat it). Distance is a lever but WEAK at this scale — verified PAIRED over 50 seeds (don't trust the single-run point estimates 0.80 vs 0.86; those were one mean each): far(0.9) vs near(0.1) at k=3 = +0.05, 80% of seeds, sd 0.08 (real but noisy, gone by k=6); far(0.9) vs near(0.2) = +0.016, 52% (COIN FLIP); far vs mid(0.5) = +0.016, 54% (coin flip); cos_bio rotation difference within noise everywhere (sd 2–3× mean). Endpoint: near/mid slightly BEAT far (q=0.9 chases outlier techs → why default q=0.90 not 1.0). So distance only detectably matters between the EXTREMES (q=0.1 vs 0.9) at early k. Lesson (again): user caught a point-estimate overclaim; always pair over seeds before asserting a quantile ordering.

**BUT the weak-distance result was itself an ARTIFACT of a spread-out seed — user caught this too (`scripts/explain_tight.py`).** Old seed = tumors from a whole TECHNOLOGY (10x 3' v3, used by many studies) → seed already spread (median pairwise 39.9), so 'near/far' had no meaningful reference (cows scattered across many fields, not one grass field). **Signature dimensionality (`scripts/explain_pcadim.py`):** PCA on 1024-dim signatures — (A) top PCs = BATCH: top-5 PCs (63% var) capture 89% of d_batch but only 52% of d_bio; d_bio needs ~50 PCs for 99%. Quantifies "batch dominates variance" (core project premise). (B) truncating the classifier input to r dims (retrieval kept full): r=50/100/1024 IDENTICAL (AUC@K 0.93, delta +0.17); aggressive r≤10 HURTS (r=5 → 0.86, delta +0.09) because it keeps batch, drops biology-in-tail. Conclusion: 1024 collapses to ~50 effective dims; L2 already zeroes the redundant tail, so PCA compression is free-but-not-a-lever (no statistical gain — effective p≈50 all along, so the p≫n variance we fought is ~50-vs-n≈24-50, only fixed by MORE PATIENTS/scale, not compression). Don't compress below ~20.

**RESOLVED — marginal per-landmark witness fixes the joint-L2 collapse (`scripts/explain_witness_uni.py`).** User diagnosed it from the scLKME paper: scLKME interprets landmarks via INDEPENDENT per-landmark Wilcoxon tests (one-vs-rest, FDR), NOT a jointly-regularized classifier. Each marginal test uses the full n on its own → no shared L2 penalty budget → p≫n collapse structurally cannot occur (their n as low as 20 works). Only meaningful in the LANDMARK basis (per-RFF-feature test is meaningless — random cosines), which also justifies landmarks. Implemented the de-confounding version: per landmark, disc_held = |AUC−0.5| of embedding_j for tumor/normal WITHIN held studies (batch-controlled biology); disc_cohort = same in the confounded Borras/Scheid seed (biology+batch); inflation = disc_cohort − disc_held (confound over-statement). RESULT — differentiated, not collapsed, biologically sensible: genuine signal (disc_held) strongest in Myeloid(0.27)/Neutrophil(0.23) > Cancer(0.15) — tumor-assoc myeloid/neutrophil are the robust CROSS-STUDY tumor marker (cancer cells heterogeneous, transfer worse); batch-carriers (high inflation, low held) = Plasma(0.40/0.08), ILC(0.40/0.10), NK(0.35/0.11); Myeloid least inflated (0.18) = most honest. **This REPLACES the fragile joint witness in the paper. Headline shifts from "Cancer cell" to "myeloid/neutrophil carry robust cross-study biology; plasma/ILC/NK are batch-inflated."** Caveats: it's univariate-discrimination not classifier-weight (a replacement not a cross-check of RFF); doesn't show k=0→k=K joint shift (that's the geometry result's job — the two complement: geometry shows w rotates to biology, marginal witness shows WHICH states carry it). **Distance = a batch-diversity dial — near→biology / far→batch (2026-07-10, `scripts/explain_batchfrac.py` + `explain_batchfrac_robust.py`).** Per retrieved pair (P,Q), batch_frac = share of the whitened squared difference on batch- vs biology-landmarks (balanced 40 vs 40, z-scored columns so 0.5 = parity; SELECTION stays raw-emb MMD, only the readout is whitened). Method A = quantile-q pick from same-diagnosis pool, B = 60 random draws/seed (many draws so the baseline isn't a noisy single pick — the small-N variance point from project start). RESULT (seed-free labels): median batch_frac q0.10=0.271 (biology-dominated) → q0.50=0.40 → q0.75=0.57 → q0.90=0.56 (batch-dominated); random flat at 0.48. **Monotone: the farther retrieval reaches, the more the difference vector is study/batch-driven, not biological.** This is the MECHANISM behind the validated q10-vs-q90 lever and answers Guillem's "what diversity": distance imports inter-lab/technological diversity that breaks tumor↔study; random sits in the middle and targets nothing (why distance should beat random at scale; ties at current N = data-limited, NOT "no batch axis" — do not reconflate these). **CRITICAL robustness caveat (user pushed to verify I didn't manufacture it by cherry-picking 40 landmarks):** random-split null (500×) far−near contrast ≈0 (sd 0.058) → not a geometric artifact. BUT the FIRST labeling (batch = high inflation, from `explain_witness_uni.py`) was itself ~NULL (far−near +0.036, z=+0.6, p=0.55) — inflation is a BAD batch proxy (overlap with true batch set 2/40). The RIGHT labeling is SEED-FREE: batch = top between-STUDY variance-ratio (eta²) landmarks on pool, biology = top within-study tumor/normal disc on held → far−near +0.287, z=+4.9, p<0.001. So: signal is real and strong, non-circular, but ONLY with the study-variance batch definition; report that one. Lesson (recurring): verify the labeling with a null before trusting a decomposition, and match the batch proxy to actual study identity. (An earlier aggregate-decomp attempt `explain_retrieval_decomp.py` was count-dominated/saturated at ~0.95 and RETRACTED — %-of-total-squared-distance can't test the lever; the per-pair whitened balanced metric can.)

**Causal leave-one-cell-type-out ablation DONE (2026-07-10/11, `scripts/explain_ablation_perm.py`, fig `explain_ablation_perm.png`).** Variant B = recompute each patient's landmark-KME signature EXCLUDING all cells of one type (emb_j^{-X}(P)=mean over non-X cells of K(x_i,l_j)); measure d_bio (held within-study tumor/normal 5-fold-CV AUC) and d_batch (mean between-study eta^2 on pool). COUNT-MATCHED null = shuffle type labels WITHIN each sample (same per-sample sizes+FLOOR mask, random membership) -> R=100 permutation p (two-sided add-one), NO distributional assumption. FINDINGS (Delta vs full; small in absolute AUC since baseline d_bio~0.89 -> report DIRECTION+significance not magnitude): (1) **Epithelial = dominant nuisance** -- removing it BOTH cuts batch most (Dd_batch -0.064, p.01) AND improves biology most (Dd_bio +0.045, p.01).
