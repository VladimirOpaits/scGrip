2. Идеи для будущих итераций (в порядке приоритета)
Идея 1: Диагностика warmup (baseline)
Что проверить:

N кластеров (Leiden).

ARI/NMI с cell_type.

kNN donor accuracy (~ случайная или нет).

Crosstab leiden × dataset_id (кластеры-батчи).

IFN R² (сохранение болезни).

Зачем:

Точка отсчёта — что даёт warmup без MMD.

Сравнение с MMD фазой.

Критерий для перехода к warmup-кластерам.

Скрипт build/diagnostics_warmup.py — уже писали.

Идея 2: Дообучение warmup до приемлемых метрик
Гипотеза: warmup может быть недостаточным (мало эпох, мало ёмкости).

Что делать:

Проверить метрики warmup.

Если kNN donor accuracy высокая (> 2/n_donors) — warmup не убрал batch effect.

Дообучать ещё K эпох, проверять снова.

Критерий остановки: kNN ~ случайная, ARI > 0.5.

Проблема: scIB на warmup противоречив (использует cell_type).
Решение: свои метрики + scIB batch correction часть.

Идея 3: Warmup-кластеры вместо cell_type для MMD
Гипотеза: кластеры из latent ловят больше структуры (подтипы, промежуточные).

Что делать:

Warmup → latent → Leiden кластеры.

MMD по leiden вместо cell_type.

Сравнить с baseline (A/B ablation).

Проблемы:

Кластеры нестабильны (seed, resolution).

Могут соответствовать батчам (если warmup не убрал batch effect).

Мало клеток на (кластер, донор) — проблема для MMD.

Кластеры дискретны, биология — непрерывна.

Правильный подход — иерархия (cell_type + leiden внутри).

Идея 4: Supervised scVI (с labels = cell_type)
Гипотеза: энкодер лучше разделит типы с labels.

Плюс: чёткие кластеры типов.
Минус:

Риск затирания промежуточных состояний.

Зависимость от качества cell_type.

Двойное использование cell_type (в loss и в MMD).

Когда пробовать: после baseline, как ablation.

Идея 5: scIB benchmark
Что использовать:

scIB batch correction (kBET, iLISI, graph iLISI).

scIB bio conservation — осторожно (ARI > 0.5, не оптимизировать до 1.0).

Плюс: сравнимо с литературой.
Минус: противоречие с целью (поиск подтипов).

Идея 6: DE анализ и сигнатуры в данных
Что делать:

Pseudobulk DE healthy vs disease (PyDESeq2).

Кластеризация DE генов → сигнатуры.

Pathway enrichment (gseapy).

Регрессия signature ~ latents (R²).

Сравнение когорт между собой.

Плюс: data-driven, не навязываем гипотезы.
Минус: дополнительная работа.

Идея 7: Per-cell скоринг аномальности
Что делать:

Для каждой больной клетки — скор аномальности (kNN до здоровых).

Threshold по квантилю здоровых (95%).

Доля affected клеток per patient.

Корреляция stage ~ доля affected.

Сравнение между 3 когортами.

Плюс: правильная постановка (клетки, не доноры).
Минус: нужны стадии болезни в данных.

Идея 8: Анализ сохранения биологии в латентах
Что проверить:

IFN R² в латентах (до и после MMD).

Регрессия каждой сигнатуры ~ latents.

Какие оси латента = какие сигнатуры.

Плюс: числовая метрика сохранения болезни.
Минус: сложнее интерпретировать.

Идея 9: Multi-seed sweep
Что делать:

Повторить обучение с 5–10 seed.

Сравнить mmd_ab между runs.

CV (std/mean) < 0.3 — стабильно.

Прокрустово расстояние между latent — маленькое.

Spearman скоров больных клеток между runs.

Плюс: доказательство стабильности для статьи.
Минус: дорого (× N время).

Идея 10: Адаптивный λ через sliding window
Что делать:

Callback мониторит mmd_ab.

Если растёт (sliding window) — уменьшает λ.

Cooldown между уменьшениями.

Min lambda — защита от нуля.

Плюс: не останавливаем обучение — адаптируем силу MMD.
Минус: сложнее код, дороже (MMD(A,B) раз в эпоху).
